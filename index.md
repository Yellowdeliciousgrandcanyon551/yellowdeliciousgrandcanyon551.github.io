## 🚀 What Is better-statusline?

better-statusline is a status display for Claude Code. Claude Code is the session you are working in, and better-statusline gives that session a visual summary. The session’s figures appear as dot-matrix rings — circular displays made from small dots — so you can read them at a glance. Beside the rings, the app shows the music you are currently playing.

The result is a simple, useful dashboard that sits with your work. It is designed for people who like a clean overview: the session numbers in one place, the current song in another, and no clutter in between.
